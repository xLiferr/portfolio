# Portfolio

Sitio estático listo para publicar con GitHub Pages. El archivo del sitio es `dist/index.html`.

## Publicar en GitHub Pages

1. Crea o usa el repositorio `portfolio` en GitHub y sube estos archivos.
2. En **Settings → Pages**, selecciona **Deploy from a branch**.
3. Elige la rama `main` y la carpeta `/dist`.
4. GitHub mostrará la URL pública cuando termine el despliegue.

Antes de publicarlo, revisa los textos y enlaces de los proyectos en `dist/index.html`.
